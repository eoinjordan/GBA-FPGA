# 480x272 LCD: HT043IBB-16A3047-H4

The panel is marked HT043IBB-16A3047-H4: a 4.3" 480x272 TFT on the common
40-pin, 0.5 mm RGB FPC that plugs into the Tang Nano 20K. No datasheet under
that part number turned up. The "3047" matches the NV3047 driver used by most
40-pin 4.3" 480x272 modules, so the figures below come from the NV3047 input
timing in an NV3047-based module specification (LG043J691K, sold by Elecrow),
checked against Sipeed's Nano 20K 480x272 samples. The design that uses them
is [tangnano20k/gba_lcd_480x272](../tangnano20k/gba_lcd_480x272/README.md).

## Interface

- 3.3 V logic. The panel takes 24-bit RGB; the Nano 20K connector wires 5-6-5
  bits (RGB565) plus DCLK, DE, HSYNC and VSYNC.
- The backlight is a series LED string (about 19-24 V at 20 mA in the module
  specification) powered by the Nano 20K's own circuit; no FPGA pin controls it
  or the DISP pin.
- Modes: SYNC-DE (all four control signals driven), SYNC (DE tied low) or DE
  (syncs tied low). The design drives all four, which is valid in every mode.

## Timing

NV3047 input timing (DCLK in MHz, horizontal values in DCLKs, vertical in lines):

| Parameter | Min | Typ | Max | Used |
|---|---:|---:|---:|---:|
| DCLK | 8 | 9 | 12 | 9 |
| Th, line period | 485 | 531 | | 531 |
| Thdisp, visible pixels | | 480 | | 480 |
| Thbp, HSYNC start to first pixel | 30 | 43 | 64 | 43 (4 + 39) |
| Thfp | 2 | 8 | 64 | 8 |
| Thw, HSYNC width | 2 | 4 | | 4 |
| Tv, frame period | 276 | 292 | | 292 |
| Tvdisp, visible lines | | 272 | | 272 |
| Tvbp, VSYNC start to first line | 2 | 12 | 64 | 12 (4 + 8) |
| Tvfp | 2 | 8 | 64 | 8 |
| Tvw, VSYNC width | 2 | 4 | | 4 |

9 MHz / (531 x 292) = 58.05 Hz. Syncs are active low. The specification asks
for exactly the typical values in SYNC mode; in DE mode only DE matters.
Sipeed's 480x272 samples use Th 525 (HSYNC 41, porches 2 and 2) and Tv 286
(VSYNC 10, porches 2 and 2); these also give Thbp 43 and Tvbp 12 and can be
selected by changing the profile in `gba_lcd_top.sv`.

Setup and hold for data, DE and syncs are 12 ns minimum around the sampling
edge. The NV3047 samples on the rising edge of DCLK (host drivers for this
controller, such as ESP32 RGB-panel configurations, clock data out on the
falling edge). The design launches every panel output from the falling edge
of its 9 MHz clock, leaving about 55 ns of setup and hold.

Power-up: the module sequences its internal supplies from the incoming VSYNC
pulses and expects the backlight about ten frames after power-on. The FPGA
starts sending frames as soon as its PLL locks, well under a millisecond after
configuration.

## Scaling 240x160 to 480x272

The GBA picture is 3:2. The largest 3:2 rectangle in 480x272 is 408x272, a
1.7x scale, centred with 36-pixel bars:

```text
 0         36                                   444       480
 | 36 px   |          408 x 272 GBA picture       |  36 px  |
```

`rtl/video/gba_to_480x272_mapper.sv` maps each panel pixel back to a GBA pixel
by nearest neighbour:

```text
source_x = floor((panel_x - 36) * 240 / 408) = floor(n * 10 / 17)
source_y = floor(panel_y * 160 / 272)        = floor(n * 10 / 17)
```

Both axes use the same 10/17 ratio, computed as `(n * 1205) >> 11`, which is
exact for every n from 0 to 407; the testbench checks all 130,560 panel pixels.
Of the 240 GBA columns, 168 are drawn two panel pixels wide and 72 one pixel
wide; rows follow the same 7:3 mix. That unevenness is the cost of the
sharpest non-integer scale; an integer 1x picture would be only 240x160.

## Bring-up order

1. Flash `gba_lcd_480x272` with the panel disconnected; check LED1, LED0 and the
   serial line (`fps=058`).
2. Power off, connect the panel with HDMI unplugged, power on.
3. Work through the pattern checklist in the project README.
