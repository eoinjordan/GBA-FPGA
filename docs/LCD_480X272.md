# 480x272 LCD integration

The marketplace screenshot establishes only the advertised size and resolution. It does not establish the electrical interface or timing.

## Required panel data

Obtain:

- exact manufacturer part number;
- FPC pin count and pinout;
- logic I/O voltage;
- pixel clock range;
- horizontal and vertical active, porch, and sync values;
- sync polarities;
- data width and ordering;
- backlight LED voltage, current, and polarity;
- whether a controller or touch IC is present.

## Scaling the GBA image

The native GBA image is 240x160 with a 3:2 aspect ratio. The largest 3:2 rectangle inside 480x272 is 408x272.

```text
480x272 panel
+----------------------------------------------+
|   36 px   |       408x272 image       | 36 px|
+----------------------------------------------+
```

The provided mapper performs nearest-neighbour coordinate conversion:

```text
source_x = floor(active_x * 240 / 408)
source_y = floor(active_y * 160 / 272)
```

It outputs a border flag outside the central 408-pixel image.

## Bring-up order

1. Confirm power rails without the panel attached.
2. Confirm pixel clock on an oscilloscope.
3. Attach the panel with backlight disabled.
4. Run the timing generator and check sync/data-enable.
5. Enable backlight at a current-limited setting.
6. Display color bars.
7. Integrate the frame buffer and mapper.

Do not infer timings from another 480x272 panel with a different part number.
