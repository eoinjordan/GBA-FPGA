# Research sources

Sources used for this repository:

- Sipeed Tang Nano 20K documentation: https://wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html
- Sipeed Tang Mega 60K documentation: https://wiki.sipeed.com/hardware/en/tang/tang-mega-60k/mega-60k.html
- FPGBA: https://github.com/Kitrinx/FPGBA
- GBATang: https://github.com/nand2mario/gbatang
- GBTang: https://github.com/fjpolo/GBTang
- GBA Studio: https://github.com/eoinjordan/GBA-Studio
- GBA Engine: https://github.com/eoinjordan/GBA-engine
- Wenting Channel video: https://youtu.be/oPbOK90aJEo
- PaperBoy S3 project write-up: https://www.hackster.io/wenting-zhang/60fps-eink-gameboy-emulator-on-m5papers3-57e4e5
- Hackaday PaperBoy S3 coverage: https://hackaday.com/2026/07/02/an-eink-esp32-based-gameboy/
- VerilogBoy: https://github.com/zephray/VerilogBoy
- RP2xxx GBA cartridge reader: https://github.com/Daft-Freak/gba-cart-read
- Sipeed TangNano-20K-example (pin constraints, 480x272 LCD timing, rPLL settings): https://github.com/sipeed/TangNano-20K-example
- SNESTang releases and installation guide: https://github.com/nand2mario/snestang/releases, `doc/installation.md` in the repository
- GBTang v1.0.0 release (bitstream, firmware and SHA-256 digests): https://github.com/fjpolo/GBTang/releases/tag/v1.0.0
- TangCore (supported boards; menu firmware on the BL616): https://github.com/nand2mario/tangcore
- NV3047 4.3" 480x272 module specification LG043J691K (input timing, pinout, backlight): https://www.elecrow.com/download/product/ESP32_Display/4.3inch/LG043J691K_SPEC.pdf
- NV3047 panel host configuration (9 MHz, 43/8/4 and 12/8/4 porches, data on the falling edge): https://www.elecrow.com/wiki/ESP32_Display_4.3-inch_HMI_Arduino_Tutorial.html

`WENTING_VIDEO_NOTES.md` paraphrases the video and the creator's write-up; it is not a transcript.
