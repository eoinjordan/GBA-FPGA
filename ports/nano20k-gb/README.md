# Tang Nano 20K GB/GBC path

Use upstream GBTang for the working Nano 20K handheld.

This repository does not fork GBTang. Run the bootstrap script, open `external/GBTang`, and follow its Gowin build or release-flashing instructions.

Local work in this repository should focus on:

- button-board wiring;
- LCD timing and scaling;
- power and charging;
- audio amplifier and speaker;
- enclosure;
- optional cartridge dumping through a companion MCU.
