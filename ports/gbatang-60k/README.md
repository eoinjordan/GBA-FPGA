# Tang 60K GBA path

Use upstream GBATang for a working GBA core on Tang Mega 60K or Tang Console 60K.

Run the bootstrap script, then follow the current TangCore/GBATang instructions in `external/gbatang`.

The repository scripts can build your GBA Studio project and copy the generated `.gba` image into an SD-card folder. Exact menu paths may change between GBATang/TangCore releases, so verify against the fetched upstream README.
